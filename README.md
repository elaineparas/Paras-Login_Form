# WebSys Laboratory: Login Form

A clean, responsive login form built for WebSys Laboratory activities. The project focuses on usability, validation feedback, and a simple interface that works well across desktop and mobile screens.

## Features

- Form validation for username and password fields.
- Immediate feedback that clears as the user corrects input.
- Password visibility toggle for easier input checking.
- Password strength meter based on length and character variety.
- Responsive layout for mobile, tablet, and desktop use.
- Social login buttons for a more polished interface.

## Tech Stack

- HTML5 for structure and semantics.
- CSS3 for layout, styling, and responsive behavior.
- JavaScript for validation, password toggling, and strength calculation.

## File Structure

- [index.html](index.html) - Main page structure and form markup.
- [style.css](style.css) - Visual styling and responsive layout.
- [script.js](script.js) - Form validation and interactive behavior.
- [assets/](assets/) - Image assets used by the social login buttons.

## How to Use

1. Open `index.html` in a browser.
2. Enter a username and password.
3. Use the Show button to reveal or hide the password.
4. Watch the strength meter update as you type.

## Notes

- The form currently simulates a successful login for demonstration purposes.
- Password values are logged to the console only for testing and classroom use.
