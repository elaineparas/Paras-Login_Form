LOGIN FORM: WebSys Laboratory
A clean, responsive, and secure login interface built with a focus on user experience and input validation.

Features
  Form Validation: Ensures all fields are filled and follows specific patterns (e.g., non-empty strings).  
  Real-time Feedback: Displays error messages immediately upon submission and clears them as the user fixes the input.  
  Password Visibility: Includes a toggle to show/hide the password to reduce login errors.  
  Strength Meter: A visual indicator that evaluates password security based on length and character variety.  
  Responsive Design: Fully adaptive layout that works on mobile, tablet, and desktop screens.
